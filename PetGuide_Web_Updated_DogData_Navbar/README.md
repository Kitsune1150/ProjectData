# PetGuide Updated

## ชุมชน
API ชุมชนรวมอยู่ใน `server.js` ส่วน CSS ของหน้าชุมชนและหน้าจัดการชุมชนรวมอยู่ใน `public/css/style.css` โดย JavaScript ที่ทำงานในเบราว์เซอร์ยังอยู่ใน `public/js/community.js` และ `public/js/community-admin.js`
โพสต์ใหม่ของสมาชิกทั่วไปมี `status: pending` และแสดงเฉพาะใน “โพสต์ของฉัน” จนกว่าแอดมินอนุมัติจากหน้าจัดการชุมชน `admin-community.html` เป็น `approved` หากไม่อนุมัติจะเป็น `rejected` พร้อม `rejectionReason` และการแจ้งเตือนในหน้าชุมชน (ตรวจผลทุก 30 วินาทีขณะเปิดหน้า หรือกดรีเฟรชได้ทันที) ผู้ใช้กดรับทราบได้และเหตุผลยังอยู่ในโพสต์ของฉัน
แอดมินเลือกเหตุผลจาก dropdown ได้หลายข้อ โดยต้องเลือกอย่างน้อย 1 ข้อเมื่อไม่อนุมัติ ตัวเลือกกำหนดใน `public/data/community-rejection-reasons.json` และตรวจสอบด้วยรายการเดียวกันทั้งหน้าเว็บและ API รหัสที่เลือกบันทึกใน `rejectionReasonCodes` ส่วนข้อความทุกข้อรวมใน `rejectionReason` สำหรับแจ้งผู้ใช้ เหตุผลของโพสต์ที่เคยปฏิเสธก่อนหน้านี้ยังแสดงได้ตามเดิม
สมาชิกลบได้เฉพาะโพสต์ตัวเอง รวมความคิดเห็นและรูปอัปโหลดของโพสต์นั้น โพสต์ของแอดมินเผยแพร่ได้ทันที โพสต์เดิมที่ไม่มี `status` ถือว่าเผยแพร่แล้วเพื่อให้ข้อมูลเก่ายังแสดงได้
เปิด `/community.html` หรือเมนู “ชุมชน” เพื่ออ่านฟีดบทความและคำถาม กรองตามหมวดสัตว์เลี้ยงและประเภทโพสต์ได้
สมาชิกใช้บัญชีเดิมในการโพสต์ แนบรูป JPG/PNG/WebP สูงสุด 4 รูป รูปละ 5 MB และเขียนความคิดเห็นหรือตอบกลับความคิดเห็นได้ รวมถึงตอบกลับคำตอบในเธรดเดียวกัน
หัวข้อรองรับ 160 ตัวอักษร เนื้อหา 10,000 ตัวอักษร และความคิดเห็น 2,000 ตัวอักษร (สูงสุด 500 ความคิดเห็นและคำตอบต่อโพสต์)
ข้อมูลเก็บใน MongoDB collection `communityPosts` ส่วนรูปอยู่ใน `public/images/community/` จึงควรสำรองทั้งฐานข้อมูลและโฟลเดอร์รูปภาพ
หลังอัปเดตให้รีสตาร์ทเซิร์ฟเวอร์ด้วย `npm run dev` แล้วเปิดหน้าชุมชน

ทดสอบ API ด้วย `npm test` โดยต้องมี MongoDB ในเครื่องที่พอร์ต 27017 หรือกำหนด `COMMUNITY_TEST_MONGODB_URI` การทดสอบใช้ฐานข้อมูลชั่วคราวชื่อ `petguide_community_test_*` และลบทิ้งหลังเสร็จ โดยไม่ใช้ฐานข้อมูลแอป

เว็บ PetGuide ชุดเดิมที่เพิ่มข้อมูลสุนัข 30 สายพันธุ์จากเอกสารที่ให้มา และปรับ Navbar ใหม่

## ปรับแล้ว
- `server.js` seed ข้อมูลสุนัข 30 สายพันธุ์
- `data/` มีไฟล์สำหรับ Import MongoDB
- Navbar ใหม่: หน้าแรก / สายพันธุ์ / ช่วยเลือกสัตว์เลี้ยง / รายการโปรด + Login/Register
- Navbar responsive บนมือถือ
- มีเส้นใต้เมนูหน้าปัจจุบัน

## รัน
`npm install` แล้วตั้ง `.env` จาก `.env.example` จากนั้น `npm start` และเปิด `http://localhost:3000`
